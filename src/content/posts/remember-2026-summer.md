# 暑假虽然没怎么出去玩，但也学到了不少东西

- 跟着我的义父继续积累金融市场方面的经验，也真正开始探索量化交易的世界。

- Agent 这边也没停下来，继续给 XiūCore 开辟功能：重构书桌前端，制作星图来梳理架构，把 XiūCore 的架构切换到 LangGraph，给她上了通讯录，继续搞了拟人化工程。只是目前暂时不打算继续推进 XiūCore 主线了，转而把这个已经花了四个月时间做出来的个人向陪伴型 Agent，让她再当便捷的通知助手的角色：给她装上监控网页的 hook，再和 XDJ 的 PA 信号做联动。或许以后有想法、有时间了，我还会继续推进 XiūCore 主线（我记得浏览器陪伴好像还只做了一半，没改完呢）。

- 上面说的是架构 Agent；此外，我也在琢磨如何精益求精地继续“养”Agent。因为我慢慢开始采用 Codex 主驾驶、OpenChamber 副手的协作方式，所以做了双 Agent 契约，方便项目同步；做了 Vision 桥、Research MCP、自养循环，以及一些乱七八糟的 Skill。还有落地了自己的一个奇思妙想比如 agent（Codex）拟人问答测试 agent（小岫）来积累拟人化工程的 few-shot，以及还有没落地的从双 Agent 对抗启发想做的小岫和季的聊天室。

- 毕竟也积累了不少经验，我也把这些经验沉淀成资产。比如开动小脑筋，把早年的 AI 绘画经验用来出图，沉淀为前端资产；同时也把积累下来的前端设计语言做成前端展厅（既有从别处看到后让我心动的，也有自己灵光乍现的想法）。

- 还玩了一些小项目。比如给鲸鱼接了个 FL 的 MCP，让它操作 MIDI 进行编曲（虽然编出来是一大坨，但挺有趣的，哈哈哈）；`dsh` 刚出来的时候，我也贡献了一个做三端的项目；还发现了 Astro 这个前端框架，于是搞了个自己的 Blog。

# 记二六夏

应是悠悠无事夏  
蝉鸣翳翳满林荫  
不择消暑  
宅读枯坐  
晨昏几时停  

行脚不辍光阴去  
双月流转蹊通径  
欣然将歇  
抬头见  
白果路银杏
