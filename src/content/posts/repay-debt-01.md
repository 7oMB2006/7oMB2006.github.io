# 晚上晚课还的债

## 哈希（Hash）

“用来算位置的号码”

## TeX / LaTeX

TeX、LaTeX 和 Markdown 一样，都是用纯文本描述文档的东西。

不过它俩更偏向：精确、专业、复杂排版，尤其是数学和学术文档。后者还是前者的封装。

## Dependabot

GitHub 检查依赖更新并自动给项目提 PR 的 bot。

## Git 的定性其实是软件

## 测试链

- ↓ 单元测试（unit）
- ↓ 集成测试（integration）
- ↓ 端到端测试（E2E）
- Smoke 冒烟，快速测试套餐
- CI 持续集成，跑一串测试
- CD 持续部署，部署上线

## AI-Native

AI 协同构建，虽然我在做 AI agent 方向，但是细化更像是这个。

## SQL

- `SQL` 是语言
- `MySQL` 是软件，是要起的服务
- `SQLite` 是一个库加一文件，嵌入式轻量化
- `MongoDB` 也是软件，走的是 NoSQL 路线，存的是文档、JSON，而不是表，是 MySQL 的竞品
- `DuckDB` 则是嵌入式，也是个库和文件，更适合海量数据，比如 K 线数据库

## Node

- `node` 是节点的英文
- `struct node` 这个才是类型名
- `typedef` 可以简化类型名

## 前端：HTML、CSS、JS、DOM

- `HTML` 超文本标记语言，属于标记语言
- `CSS` 叠层样式表，属于样式表语言
- `JavaScript` 前端编程语言
- `DOM` 浏览器把 HTML 解析后得到的对象树
