# Desktop for Step Code [Release v0.2.0](https://github.com/7oMB2006/desktop-for-step-code/releases/tag/v0.2.0) 社区第三方预览版发布🎉

由 [@7oMB2006](https://github.com/7oMB2006) 和 [@Zi-Yi-Ming](https://github.com/Zi-Yi-Ming) 锚定上游 Step Code 开发。

我们的初衷是在官方尚未推出正式 Desktop 前，为社区预览补足窗口期。

欢迎大家来体验，也欢迎来提建议！同时我们也和官方 @周旭 老师对接，正式版 Desktop 正在路上🚗

目前仅支持 Winx64，GitHub 直接下载 setup 文件，开箱即用。快捷登录官方 Plan 账号~

*声明：当前锚定的上游还有很多问题待推进，比如即使开了 autopilot 自动驾驶，也会卡在审批。这些问题会继续跟进修复！*
